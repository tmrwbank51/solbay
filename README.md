SOLBAY is an original open-world crime game in a sun-soaked modern coastal city: explore Sol Bay on foot and by car, steal cars, outrun the police under a 5-star wanted system, run missions for cash, and watch the city shift from golden day to neon night with rain. Every street, character, vehicle, name and sound is original, built procedurally in three.js with zero network requests. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. WASD to move/drive, E to enter/exit a car, Space to jump/handbrake, F to punch, M for missions, R for radio, T for weather, P to pause.
